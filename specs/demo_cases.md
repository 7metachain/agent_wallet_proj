## Killer Demo: 智能收益优化器

### 场景描述

用户有跨链资产，希望找到最优收益方案，Bot 自动分析并执行复杂的跨链+多协议操作。

```
"我在 Ethereum 上有 10,000 USDC，帮我找到最好的收益方案"
```

### 简化版（快速 Demo）

```
User: "把我 Base 上的 USDC 转到 Monad，一半存 Curvance，一半质押"

Bot: 📋 交易计划：
     1. 跨链 Base → Monad (LI.FI)
     2. 50% USDC → Curvance (5.8% APY)

```

## 演示技巧

1. **循序渐进**: 先展示简单功能，再展示复杂组合
2. **强调价值**: 突出"一句话完成复杂操作"
3. **可视化**: 使用图表展示收益对比和交易流程
4. **实时反馈**: 展示交易执行进度和状态
5. **错误处理**: 演示错误场景的友好提示
